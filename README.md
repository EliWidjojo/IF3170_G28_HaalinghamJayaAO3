# Task2_AI_13524116

## Description
This project implements Local Search, DTL, LR, SVM.

## Requirements
Python 3.13 or later is recommended.<br>
Install the required libraries using: <br>
` pip install numpy pandas scikit-learn `

## How to Run?
Run the commands from the root directory of the project. <br>
Local Search: <br>
` python src/local_search/src/main.py ` <br>
DTL, LR, SVM: <br>
` python src/dtl_lr_svm/src/main.py `
